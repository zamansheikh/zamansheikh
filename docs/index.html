Hard problems

Three things most teams buy instead of build.

A video engine, a text shaper and a browser for AI agents. Each one started as a blocker on a real product and ended as something other people now install.

  1. 01 · Real-time video

    Voxa RTC

    An Agora-compatible real-time video engine running on self-hosted LiveKit. Same classes, signatures, error codes and callback order as agora_rtc_engine, so a live-streaming app moves off per-minute pricing without rewriting a screen.

    • Self-hosted media servers, owned end to end
    • Beauty filters and AR effects on the capture path
    • voxa_rtc_engine 0.7.3 on pub.dev
    Read the case study →

  2. 02 · Text shaping

    bangla_pdf

    Real OpenType shaping for Bangla, written in pure Dart and ported to TypeScript. Conjuncts, vowel signs and reph render correctly in generated PDFs, and the text copies back out as clean Unicode.

    • No native dependencies, runs anywhere Dart runs
    • Dart and npm extractors produce byte-identical text
    • bangla_pdf 1.9.2 on pub.dev · bangla-pdf 0.2.2 on npm
    Read the case study →

  3. 03 · AI tooling

    Pagewright

    Gives an AI agent a real browser. An MCP server talks to a Chrome extension, so the agent navigates, reads and acts in an actual tab, with the user's sessions, instead of a headless sandbox.

    • MCP server plus a Chrome extension
    • Works with any MCP client
    Read the case study →
